# 진동 점자 뱅킹 · Haptic Braille Bank

시각장애인이 **진동과 점자**만으로 은행 잔액을 확인하고 송금할 수 있게 하는 모바일 웹 프로토타입입니다. 은행 개인정보(잔액·계좌번호·비밀번호)가 **음성으로 새어나가지 않는 것**을 핵심 전제로 설계했습니다.

> 프로토타입입니다. 은행 데이터는 모두 가상이며 실제 이체·조회는 이뤄지지 않습니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 됩니다.
진동은 Android Chrome·삼성 인터넷 등에서 동작하며, 미지원 환경(iOS Safari 등)에서는 소리와 화면으로 대체됩니다.

```
open index.html      # macOS
```

## 주요 기능

- **잔액 확인 / 거래 내역 / 송금** — 모든 숫자를 한국 점자 규정 규격의 6점 배열로 표시
- **손끝으로 문질러 읽기** — 화면 아래 고정된 점자 칸을 손가락으로 훑으면 볼록한 점은 긴 진동, 평평한 점은 짧은 진동
- **순서대로 재생** — 숫자를 시간 순서의 진동 리듬으로 읽어 줌
- **점자 입력** — 0~9 스테퍼로 한 자리씩 입력 (금액·계좌번호·비밀번호)
- **프라이버시** — 잔액·비밀번호 등 민감 값은 음성 안내에서 완전히 제외. 자리 위치("둘째 자리 입력")만 안내
- **화면 크기 보정** — 신용카드로 보정해 실제 점자 규격 크기로 렌더링

## 기술 스택

순수 HTML + CSS + JavaScript **단일 파일**. 프레임워크·라이브러리·빌드 도구 없음.

| API | 용도 |
|---|---|
| Vibration API (`navigator.vibrate`) | 진동 점자 (점마다 개별 호출로 모터 스로틀링 회피) |
| Web Speech API (`speechSynthesis`) | 앱 자체 한국어 음성 안내 (비민감 정보만) |
| Web Audio API (`AudioContext`) | 점자 톤 신호, 무진동 환경 대체 |
| Pointer Events + `getBoundingClientRect` | 손끝 문지르기 추적 + 기하 히트테스트 |
| localStorage | 설정·목업 은행 상태 저장 |
| ARIA (live region·role·label) | 접근성 계층 (민감 값은 의도적으로 제외) |

## 알려진 한계

- 웹은 진동 **세기** 조절, 스크린리더 감지, 제스처 통과가 불가능 — 스크린리더를 켠 채 문지르기까지 살리려면 네이티브(iOS Core Haptics / `AllowsDirectInteraction`, Android `VibrationEffect`)가 필요
- 실제 은행 연동은 오픈뱅킹 API + 백엔드 + 본인인증 필요
- 진동·소리·실기기 제스처는 실제 단말에서 최종 확인 필요
